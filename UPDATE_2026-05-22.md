### API key embedded

- `src/services/config.ts:EMBEDDED_GEMINI_KEY = 'AIzaSyCRjO...'`
- `getEffectiveApiKey(userKey)` ưu tiên user override, fallback embedded
- Settings KHÔNG có ô nhập Gemini key — mở app là dùng được
- Tab Khác: gỡ hết text "Cần Gemini API key"

**Risk known**: key public trong APK, free 1500 req/ngày chia cho tất cả user. TODO backend proxy khi có >1k user thật.

### DB robustness

- Schema split thành từng câu, try/catch riêng
- `getDb()` guard race condition bằng promise singleton
- `ensureCategoriesSeeded()` re-seed nếu DB rỗng
- `resetDatabase()` xoá hoàn toàn + re-init (button trong Settings danger zone)
- Fallback in-memory categories nếu DB hoàn toàn fail → UI vẫn render

## Cách test trên iPhone (Windows + iOS)

1. iPhone: cài **Expo Go** từ App Store
2. Máy Windows: `cd D:\CLAUDE\BopAI && npx expo start --clear`
3. Mở **app Camera mặc định iOS** (không phải Expo Go) → chĩa vào QR code trong terminal
4. iPhone hiện banner "Open in Expo Go" → bấm → app load
5. iPhone + máy phải cùng wifi. Nếu wifi công ty chặn → mở hotspot iPhone

**Nếu app cũ trên Expo Go cache còn dữ liệu test**: vào **Cài đặt → Khu vực nguy hiểm → Reset DB** → bấm "Reset DB (xoá hết)".
